# TR-B1 patch notes

All 18 findings were fixed and none were skipped. 13 pages patched, 62 edits. Pages with no findings: tr-b1-copula-ol, tr-b1-past-continuous-iyordu, tr-b1-reason-digi-icin.

## tr-b1-causative-voice
- Causee case reversed (error): **fixed**. The prose now uses the accusative for intransitive bases and the dative for transitive ones (G&K §13.2.1). The uyut- example note now gives the right reason. The pitfall is rewritten as "Mis-casing the causee": *Ali'yi koşturdum* is now ✓, and the ✗ is the genuinely wrong *\*Ali'yi kapıyı açtırdım* (✓ *Ali'ye kapıyı açtırdım*).
- -t vs -DIr distribution (error): **fixed**. -t is now limited to polysyllabic stems ending in a vowel, l or r (G&K §8.2.1.1). *kapat → kapat-* is replaced by *otur → oturt-*. The -DIr bullet now covers monosyllabic l/r stems and polysyllabic stems ending in other consonants (*konuş → konuştur-*). The -t pitfall gives a two-condition check (öl- → öldür-).
- içir- "regular" (misleading): **fixed**. It is now described as a member of the irregular -Ir set rather than the regular -DIr form, to be learnt like the suppletive pairs.

## tr-b1-abstract-postpositions
- *onların hakkında / hakklarında* (error): **fixed**. The table row is now *onlar | hakkında*, and the header "pronoun (genitive)" is now "pronoun". The intro and formation prose now name the genitive-attracting pronouns and state the plural *onlar* exception (G&K §17.2.1, §17.3.2 (iv)–(v)).
- "Group-1 (ile, için)" and "locative/ablative" (misleading): **fixed**. The text now says "simple postpositions (ile, için)". The forms are described as noun + possessive + fixed case ending: locative hakkında, ablative yüzünden, dative yerine; boyunca has -CA.

## tr-b1-converb-while-yken
- "Imperfective aspect only" (error): **fixed**. The bullet is now "Aorist by default, never -DI" and adds -mIş (*gelmişken*) and -(y)AcAk (*gelecekken*) per G&K §26.2.3 (ii). The aorist label -r/-ar/-er is now -r/-Ar/-Ir. The -DI pitfall no longer says that a completed event is incompatible with -ken.

## tr-b1-obligation-periphrases
- *bitmemiz gerekiyor* (error): **fixed**. Now *bitirmemiz gerekiyor*.
- "Only zorunda takes -mAk" (misleading): **fixed**. The pitfall is now about a personal obligation: -mA + possessive. *Gitmek lazım* is given as the impersonal pattern ("one has to …"). The ✗ *Gitmek lazımım* stays, re-glossed as "lazım cannot take a person ending".
- ✗ *Vizeyi almak malıyım* (misleading): **fixed**. That line is replaced by "Less precise: Vizeyi almalıyım (grammatical, but presents it as your own decision)". The ✓ zorundayım line is unchanged, so the contrast is now about meaning, not grammaticality.

## tr-b1-olarak
- *avukatı olarak* wrongly marked ✗ (misleading): **fixed**. The ✗ is now the genuinely wrong dative *\*avukata olarak*, matching the curriculum fix. "Always bare" is replaced by "no case suffix — though a possessive is fine: şirketin avukatı olarak".
- *masaya benziyor* "would need gibi" (error): **fixed**. The note now says *masaya benziyor* (benze- + dative) describes resemblance, not a function the object fills.

## tr-b1-participles-dik-acak
- "Both suffixes … 4-way harmony" (error): **fixed**. -DIK has 4-way harmony and -(y)AcAK has 2-way harmony.

## tr-b1-passive-voice
- *Burada sigara içilmez* used as the impersonal passive (error): **fixed**. The example and the when-to-use item now use *Çimlere basılmaz* ("Keep off the grass"): intransitive bas- with the dative, so it is a true impersonal passive (G&K §13.2.2.3). This matches the curriculum's switch away from the sigara example.
- "Always use tarafından" (misleading): **fixed**. The pitfall now covers human agents only. Inanimate causes take the ablative or locative, illustrated with *Fırtınada bütün evler yıkıldı* (G&K §13.2.2 ex. 44). The when-to-use item now says "When a human agent is named, put tarafından after…".

## tr-b1-real-conditional
- -(I)r aorist rule (error): **fixed**. Formation now describes -(A/I)r: -Ar on monosyllabic stems except the 13 -Ir verbs, -Ir on polysyllabic stems, and -r after vowels. The positive heading and the in-text -(I)rsA labels are now -(A/I)rsA, as in the curriculum commonError. The title is left as is, to match the curriculum name.
- False "irregular aorists" git/et/de (misleading): **fixed**. The callout now presents them as regular (-Ar with t→d; de- + -r) and lists the 13 -Ir verbs with *alırsa, gelirse, olursa*.

## tr-b1-conditional-irrealis
- "aorist conditional -Ir/-Irdı" (misleading): **fixed**. The form is now relabelled "aorist + past copula -(A/I)rdI (alırdım, yapardım)" in when-to-use, the example note and the pitfall. The -IrdI label in the -sAydI item is now -(A/I)rdI.

## tr-b1-reciprocal-voice
- ✗ *yardımlaştık* (error): **fixed**. The ✗ is now *\*dinleştik* (✓ *birbirimizi dinledik*). The pitfall adds that noun + -lAş does build mutual-activity verbs, and that *yardımlaştık* is standard.
- selamla-/mektupla- misanalysis (misleading): **fixed**. The table row is now "mektup (noun) | mektuplaş-". The callout keeps selamla- + -ş, which is a real verb stem, and explains mektuplaş- as noun + -lAş (G&K §7.2.2.1). The example note and the when-to-use list are updated to match.
