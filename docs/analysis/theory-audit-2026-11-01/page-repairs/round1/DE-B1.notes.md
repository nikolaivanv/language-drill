# DE-B1 patch notes

All 12 findings on 10 pages fixed; none skipped. Verified against Durrell where a § was cited (7-adverbs hineingegangen, §12.5c beim/am, §4.2.1b–c abstract nouns, §4.4.1a masculine countries, §15.1.2 double infinitive).

## de-b1-hin-her
- hinein does not split → fixed: the formation paragraph now says the whole compound is the prefix (one unit at clause end, joined in the participle and subordinate clauses). The example is now "Sie geht hinein. → Sie ist hineingegangen." with a matching gloss, and the note explains hineingehen / hineingegangen / dass sie hineingeht.

## de-b1-subordinate-conjunctions
- ausgehen → fixed: the note now names `ausmachen`.

## de-b1-konjunktiv-ii-past
- "participle always final" → fixed: the callout now says the participle is last only in a main clause, the auxiliary goes last in a subordinate clause (wenn ich das gewusst hätte), and a modal takes a double infinitive (Ich hätte früher kommen sollen / dass ich früher hätte kommen sollen). The formation paragraph now says "at the end of a main clause".

## de-b1-praeteritum
- Strong-verb endings → fixed: the callout now says strong wir and sie/Sie take -en (kamen, gingen). The false "but" contrast is gone: 1sg/3sg have no ending in both classes (machte, kam), and only strong verbs show the bare ablaut stem.

## de-b1-comparison-attributive
- Superlative "always weak" → fixed: the table row is now "-e (weak) / -er (after mein etc., masc.)" with "der beste Plan / mein bester Plan". The callout now says "usually" and adds mein bester Freund, unser größtes Problem.
- Comparative row -es vs ein besserer → fixed: the cell now reads "-er (after ein, masc.) / -e (weak)".
- Extra (same page, dependent): the example note said "Never am schönsten Tag", but am schönsten Tag (= an dem) is grammatical. It now reads "*der am schönsten Tag", matching the pitfall.

## de-b1-progressive-equivalents
- beim labelled colloquial → fixed: what-is-it now says "the standard beim + …". When-to-use says beim is standard and the am-form is the colloquial/regional one. The beim example note says it is standard and fine in writing, unlike "Ich bin am Kochen". The am-pitfall now offers "Ich bin beim Lesen" as a formal alternative.

## de-b1-genitive
- Weak masculines → fixed: the formation paragraph adds the exception (des Studenten, des Kollegen, des Herrn; des Namens, des Herzens), the masculine table row adds "weak masc. -(e)n: des Studenten", and the pitfall is now scoped to "(non-weak)" with an added warning against *des Studentes.

## de-b1-articles-use
- Masculine country article "always" → fixed: feminine and plural names are always; masculine names are usual but optional ((der) Iran, im Irak / in Irak). The table rows now show "(der) Iran" and "aus dem Iran / aus Iran" (same for Irak). The pitfall already covered only feminine and plural names.
- Abstract nouns / "Die Geduld ist eine Tugend" → fixed: the list item now says the article is optional in general statements and usually dropped in proverbs (Geduld ist eine Tugend). The example is replaced with "Die Zeit vergeht schnell." / "Time passes quickly.", and its note contrasts "Ich habe keine Zeit" and the article-less proverb.

## de-b1-dass-clause-perfekt
- "always participle first, auxiliary last" → fixed: "always" is removed from the pitfall, and the pitfall adds the modal-Perfekt exception (dass sie es hat machen müssen). The formation text now reads "With a participle, the order at the end is…". The warn callout now says the auxiliary comes after the participle and notes the modal exception.

## de-b1-passive-werden
- "Modal passive cluster always ends with werden" → fixed: the callout now scopes it to main clauses and adds the subordinate order (…, weil das Formular ausgefüllt werden muss). The pitfall now starts "In a main clause, …". The Perfekt/Konjunktiv auxiliary-first case (hätte überprüft werden sollen) was left out as beyond B1 scope; the rule no longer says "always", so it is no longer contradicted.
