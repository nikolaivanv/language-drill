## tr-a1-demonstratives
- #1 **real**. G&K §6.2 (pronominal n): with o and bu/şu, n appears before every case suffix, the plural -lAr, -CA and -sIz (ona, bunu, şunlar, bunca). It is not a vowel-hiatus buffer. Formation prose now reads "inserted before every case suffix — vowel- or consonant-initial alike (bunu, bunda) — and before the plural (bunlar)". This matches the existing pitfall.
- #2 **real**. G&K §18.3.1: the stem is bura-/şura-/ora- (never bare), and burası = bura- + 3sg possessive -(s)I. Possessive forms such as burasında also exist ("şuran 'this part of you'"). Callout rewritten: use burada for "here"; burasında exists but means "at this spot / in this part (of something)". The "stem shortens" claim is gone.
- #3 **real**. Same source (§18.3.1). The prose "inflect like ordinary nouns ending in a vowel" is now "built from the stems bura-/şura-/ora- plus -sı; the everyday case forms attach case to the bare stem". The "what is it?" sentence is adjusted the same way. The curriculum line ("burası/orası inflect like nouns") is loose but not contradicted.
