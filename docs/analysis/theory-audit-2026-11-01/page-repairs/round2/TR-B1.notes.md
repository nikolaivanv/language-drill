# TR-B1 round-2 claim verdicts

## tr-b1-olarak
- #1 **real**. G&K §16.1.2: "With the exception of formations with -lI and -sIz, most derived adjectives can modify verbs only indirectly … or by standing as complement to olarak". §16.1.9 still uses yazılı olarak. Rewrote the "when to use" bullet: most derived adjectives (-sAl bilimsel, -(y)IcI geçici, fixed yazılı) need olarak; many -lI/-sIz adjectives work directly (dikkatli sür). The bullet also listed `-lI` twice, now fixed. Pitfall now names -sAl / -(y)IcI and drops -lI. *bilimsel anlattı stays the ✗ example (matches G&K ex. 5).

## tr-b1-participles-dik-acak
- #1 **real**. The note called `-ığı` the possessive. Now: possessive `-ı`, `yaptık + ı → yaptığı`.
- #2 **real**. The callout tied k→ğ to the 3rd-person possessive only. Now: softening before any vowel-initial possessive (okuduğum, okuduğu), with k kept before -lArI (okudukları). This matches the page's table.

## tr-b1-past-continuous-iyordu
- #1 **real**. kalkıyordu note: kalk- triggers only the buffer -ı-. -du after -yor is the same for every verb.
- #2 **wrong**. G&K §8.2.3.3 (-(I)yor): a stem-final a/e "becomes high" before yor. ye- → yiyor is the same process as bekle- → bekliyor, and the orthography shows it (§2.6, ye/de). The page describes the whole class as "a final a/e drops" + -Iyor, and the note follows that same analysis. No change.
- #3 **real**. Removed "here always back and rounded" (-lar is unrounded; -m/-n/-k have no vowel).
- #4 **overstated**. The callout already covers the 3pl reordering. While fixing #3 I added "In the 3rd person plural, -lar comes before the past suffix (see below)" to the endings bullet, so the chain no longer reads as universal.
- Not claimed, flagged: the callout stars `*geliyordular`. G&K §8.4(iii) says the 3pl -lAr's "preferred position is between" the tense and copula, "but it may also come at the end" (kat-sa-ydı-lar). The tr-b2-compound-past-hikaye page calls gitmiştiler standard. These two pages conflict, and the asterisk is arguably too strong. I left it unchanged because no claim covers it.

## tr-b1-reflexive-voice-kendi
- #1 **real**. kendini giydi does not mean "got dressed". The pitfall now says to use the -(I)n verb alone. It adds that kendi + transitive verb is the pattern for verbs outside the closed set (kendimi gördüm), and that with giy- it would not mean "get dressed".

## tr-b1-when-converbs
- #1 **real**. Table cell "-(y)i (→ ∅ + buffer)" → "-i (+ n before -de)". G&K §8.1: the 3sg possessive is -(s)I(n), with -n before a case suffix.
- #2 **real**. G&K §2.1(b): "only a few verbs" (et-, git-, güt-, tat-) change their final consonant. The callout now says so and contrasts bitince / atınca.
- #3 **real** (omission that left the table unexplained). Added one sentence after the formula: k→ğ before a vowel-initial possessive, -nde after the 3sg possessive, and k kept in geldiklerinde.
