# Round 3 — TR verdicts

## tr-a1-clock-time-dates
- #1 **real**. The accusative -(y)I has four-way harmony; the dative and locative have two-way harmony (G&K ch. 1 vowel harmony; §8.1.4 case suffixes). The sentence now says the dative has the same two-way harmony as the locative (dörde) and the accusative harmonises four ways (ikiyi, üçü).

## tr-a2-ability-necessity
- #1 **real** (overgeneralised). Vowel sequences do occur in Turkish (saat, aile). The buffer -y- is the repair at this suffix boundary (G&K §6 buffer y). The text now reads "The suffix vowel cannot follow the stem vowel directly."

## tr-a2-correlative-conjunctions
- #1 **wrong**. Already judged in round 2. G&K §20.4 says ne…ne takes affirmative or negative predicates, "each with a separate intonation contour and stress pattern". No change.
- #2 **wrong**. G&K §20.4: "The second conjunct can be placed after the predicate, but only when the predicate is affirmative." No change.
- #3 **wrong**. The same §20.4 passage covers var/yok. No change.

## tr-a2-nominalization
- #1 **real**. The stem is oku-, so the last stem vowel is u, not o. The pitfall now reads "_okumak_ has the stem oku-, whose last vowel (u) is a back vowel".

## tr-a2-reflexive-reciprocal-pronouns
- #1 **real**. The 1st- and 2nd-person possessives end in a consonant, so no -y- appears. A 3rd-person possessive takes pronominal -n- before case (G&K §18.1.3: "n has to be attached to the 3rd person forms kendi, kendisi and kendileri when these are inflected for case, e.g. kendine/kendisine"; §6.2). Front-vowel kendi never takes -a. The rule now reads "add [-e] after the possessive; after a 3rd-person possessive the buffer -n- comes first: kendime, kendimize, kendisine, kendilerine." This matches the accusative table (kendisini, kendilerini).

## tr-b1-causative-voice
- #1 **real** (muddled example). içir- is a regular member of the ~30-verb -Ir class (G&K §8.2.1.1 lists bitir, düşür, pişir under -Ir). It is not a suppletive pair like gir-/sok-, which is G&K's own example of a verb that takes no causative. The page no longer presents içir- as "similar" to the suppletive pairs. It now says the -Ir / -Ar / -It verbs "need the same care": iç- gives iç-ir-, not the regular -DIr form, and both kinds must be learnt as vocabulary. I deliberately did not add an asterisked *içtir-.
- #2 **overstated**, no change. G&K §8.2.1.1: "Around thirty monosyllabic stems … combine with one of the forms -It, -Ir, -Ar or -Art." The book does not say which stems take which suffix, so they must be learnt individually. A closed class whose members are listed is still lexically idiosyncratic, so there is no contradiction.

## tr-b1-converb-while-yken
- #1 **real**. The main-clause subject is the overt burası. The note now says ben is stated because it differs from the main-clause subject, burası, and because çocukken carries no person ending.

## tr-b1-passive-voice
- #1 **real**. The passive of yaz- cannot mean "written to". With a person subject, yazıldım is idiomatic for "I enrolled / signed up" (kursa yazıldım). The gloss now reads (idiomatically «I enrolled / signed up»).

## tr-b2-as-if-gibi
- #1 **real**. yorul- means "get tired", so "has been very tired" mistranslates it. With görün-, -mIş gibi reports an impression from appearance (the «seem» use), not a counterfactual. The gloss is now "She looks very tired." The note now calls this the «seem» use: unlike a pretence, the situation may be real. That fits the page's own pitfall 3 (duymuyor gibi → «seem» reading).
- #2 **real** (one-word hedge). G&K §26.1.5 / §26.3.8(ii) frames these clauses as comparison with an imagined event *or* as "suggesting an underlying motivation or emotion". With sanki they signal non-factual status. The page's 4th example is not counterfactual, so "signalling" became "usually signalling".

## tr-b2-instead-of
- #1 **real**. -DIk is not evidential (that is -mIş). G&K treats -DIK as the non-future participle / factive nominaliser (ch. 24–25). It is now "the non-future (factive) participle `-DIk`", which is consistent with the «given that you cried» gloss.
